## What is MCP?

MCP stands for **Model Context Protocol**. It gives AI assistants a standard way to connect to tools, services, and external systems.

In the SGDS workflow, MCP is useful because it lets the assistant work with real context instead of just text prompts. For example, it can:

- read a selected Figma frame
- inspect a connected workspace or tool
- use richer context to generate more accurate SGDS code

## Why it matters

Without MCP, you have to describe your design or setup manually. With MCP, the assistant can inspect the source directly and produce more reliable results.
